# 동호회 사진·영상 앨범

로그인 없이 누구나 링크로 보는 동호회 앨범 사이트입니다. GitHub에 사진을 올리면 1~2분 뒤 사이트에 자동으로 반영됩니다.

## 처음 한 번만: 사이트 만들기

1. https://github.com 에 가입하고 로그인합니다.
2. 오른쪽 위 **+** → **New repository**. 이름은 예: `club-album`, **Public** 선택 → **Create repository**.
3. 새 저장소 화면에서 **uploading an existing file** 링크를 누르고, 압축을 푼 폴더 안의 파일·폴더를 **전부** 끌어다 놓은 뒤 **Commit changes**.
   - `.github` 폴더가 안 보이면(숨김 폴더) 아래 "배포 설정 파일 직접 만들기"를 따라 하세요.
4. 저장소의 **Settings → Pages** → Source를 **GitHub Actions** 로 바꿉니다.
5. **Actions** 탭에서 "앨범 사이트 배포"가 초록 체크가 되면 끝. 안 돌고 있으면 그 항목을 눌러 **Run workflow**.
6. 사이트 주소: `https://<내 아이디>.github.io/club-album/` — 이 링크를 단톡방에 공유하세요.

### 배포 설정 파일 직접 만들기 (3번에서 .github 폴더가 안 올라갔을 때)
저장소에서 **Add file → Create new file** → 파일 이름에 `.github/workflows/deploy.yml` 입력 → 압축 파일 안의 같은 파일 내용을 붙여넣기 → **Commit changes**.

## 동호회 이름 바꾸기
`site.json` 파일을 열고 연필(✏️) 아이콘 → `name`, `sub` 수정 → **Commit changes**.

## 매달 사진 올리기
1. 저장소에서 `albums` 폴더로 들어갑니다.
2. **Add file → Upload files**.
3. 컴퓨터에서 `2026-11-02 정기전 vs 한강FC` 처럼 **날짜 + 활동이름** 으로 폴더를 만들어 사진·영상을 넣고, 그 **폴더째** 끌어다 놓습니다.
4. **Commit changes** → 1~2분 뒤 사이트에 나타납니다.

- 활동 설명은 폴더 안에 `메모.txt` 로 넣으세요. 유튜브 주소를 한 줄에 적으면 영상으로 보입니다.
- 사진은 자동으로 웹용 크기로 줄여서 올라가므로 원본 그대로 올려도 됩니다.
- 영상은 사이트에 올라갈 때 자동으로 웹용(최대 1280px)으로 줄어듭니다. 보통 원본의 1/3~1/10 크기가 돼요.
- 아이폰 HEIC 사진은 보이지 않습니다. 카카오톡으로 받은 사진(JPG)이나 JPG로 내보낸 사진을 올려 주세요.
- 잘못 올린 사진은 파일을 눌러 오른쪽 ⋯ → **Delete file** 로 지웁니다.

## 사이트에서 볼 수 있는 것
- **한 장씩 넘겨보기**: 사진이 천천히 움직이며 자동으로 넘어가는 슬라이드쇼
- **파노라마 전체보기**: 사진이 여러 줄로 흘러가는 주마등 화면
- **영상관**: 그 달(또는 올해)의 영상·유튜브를 목록으로 모아 차례로 자동 재생
- **추억영상 만들기**: 사진을 배경음악과 함께 영화처럼 재생하고, 영상 파일(MP4)로 저장해 단톡방에 공유

## 추억영상 배경음악 넣기
저장소의 `music` 폴더에 mp3·m4a 파일을 올리면 사이트의 '추억영상 만들기'에서 고를 수 있습니다. 파일 이름이 곡 이름으로 보여요.
- 음악을 올리지 않아도 사이트가 직접 연주하는 '기본 신나는 음악'이 있습니다.
- 보는 사람이 자기 컴퓨터의 음악 파일을 골라 쓸 수도 있습니다(그 사람 화면에서만 쓰이고 올라가지 않음).
- 영상을 단톡방·SNS에 공유할 거라면 저작권이 자유로운 음악을 쓰세요(유튜브 오디오 보관함, 공유마당 등).
- 영상 파일 저장은 컴퓨터의 크롬·엣지에서 가장 잘 됩니다. 저장하는 동안 영상 길이만큼 재생되니 화면을 띄워 두세요.

## 큰 영상 올리기
| 영상 크기 | 방법 |
|---|---|
| 25MB 이하 | 위의 웹 업로드 그대로 |
| 100MB 이하 | **GitHub Desktop** 앱으로 올리기 (아래) |
| 그보다 큰 영상, 경기 전체 영상 | 구글 드라이브나 유튜브에 올리고 주소를 `메모.txt`에 한 줄로 적기 |

### GitHub Desktop으로 올리기 (100MB까지)
1. https://desktop.github.com 에서 설치하고 GitHub 계정으로 로그인합니다.
2. **File → Clone repository** 로 내 저장소를 컴퓨터에 받습니다(처음 한 번만).
3. 받은 폴더 안의 `albums` 폴더에 활동 폴더를 복사해 넣습니다.
4. GitHub Desktop 왼쪽 아래 Summary에 아무 말(예: 11월 정기전)을 쓰고 **Commit to main** → 위쪽 **Push origin**.

### 구글 드라이브 영상 (크기 제한 없음)
1. 드라이브에 영상을 올리고 오른쪽 클릭 → **공유** → 일반 액세스를 **링크가 있는 모든 사용자**로 바꿉니다.
2. **링크 복사** 한 주소를 그 활동의 `메모.txt` 에 한 줄로 붙여넣습니다.
3. 드라이브 영상은 드라이브에서 처리가 끝나야 재생돼요(올린 뒤 몇 분). 영상관에서 끝나도 다음 영상으로 자동으로 넘어가지 않으니 목록에서 눌러 주세요.

## 여러 명이 같이 올리기
**Settings → Collaborators → Add people** 로 운영진의 GitHub 아이디를 추가하면 함께 올릴 수 있습니다. 보는 사람은 계정이 필요 없습니다.

## 용량
GitHub Pages는 사이트 1GB까지 무료입니다. 사진은 자동으로 줄어들어 한 장에 약 0.3~0.6MB라 수천 장까지 괜찮고, 영상은 유튜브 링크를 쓰면 용량 걱정이 없습니다.
